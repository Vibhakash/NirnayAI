VERDICT RULES:
- ELIGIBLE: Clear numeric evidence found AND the value satisfies the threshold
- INELIGIBLE: Clear numeric evidence found AND the value does NOT satisfy the threshold
- NEEDS_REVIEW: Use when: value text is present but ambiguous/illegible; conflicting values found; unit is unclear; document appears relevant but key figure cannot be read with confidence
- NEVER leave ambiguous cases as INELIGIBLE — always use NEEDS_REVIEW when uncertain

INDIAN NUMBER RULES:
- 1 crore = 10,000,000 (one crore rupees)
- 1 lakh = 100,000 (one lakh rupees)
- Financial year runs April to March (FY 2023-24 = April 2023 to March 2024)
- Annual turnover, revenue, and sales all refer to the same concept
